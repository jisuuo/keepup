오늘의 학습 계획을 제안한다. 아래 순서로 하고, 파일을 수정하지 않는다.

1. `date +%F`로 오늘 날짜를 구한다. DAY 번호는 `LEARNING_LOG.md` 마지막 DAY + 1(날짜와 무관한 회차 번호), 주차(토~금)와 요일은 2026-10-10(토) 시작 기준으로 날짜에서 계산한다.
2. `LEARNING_LOG.md` 마지막 행과 가장 최근 `blog/posts/` 글의 「5. 막힌 것 / 다음에 볼 것」을 읽는다.
3. `ROADMAP.md`의 해당 주차 행(목표·체크리스트·남길 문서)과 자료구조 체크 맵의 해당 주차 항목을 읽는다.
4. `git status --short`와 `git log --oneline -5`로 진행 상태를 확인한다.
5. 아래 형식으로 짧게 답한다.

```
DAY NNN · N주차 · 요일
어제: 한 줄 (밀린 것·다음에 볼 것 포함)
오늘 목표 1개: ...
오늘의 질문 1개: Q? — 질문 형태로 (답은 쓰지 않는다)
시간 배분: 구현 5~30분 / 질문 따라가기 30~45분 / 마감 45~60분
```

- 금요일이면 목표 대신 주간 회고(완료 조건 체크, weekly-review 글)를 제안한다.
- 목표는 반드시 1개만. 밀린 항목이 있으면 그것을 먼저 제안하고 이유를 한 줄로 쓴다.
